IV. Deploying This Release
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

There are two files in this release:

- KiGa3000-1.1.2-src.zip 
The first is the source archive, interesting only to developers.

- KiGa3000-1.1.2.zip

The second is the full release.  This contains all
you need to run Kiga3000 aside from the MySQL database itself and
the Java VM.  Most people will have success with this simply
downloading and following the steps in the INSTALL.txt file
within the archive.
